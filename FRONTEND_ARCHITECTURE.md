# SalesBrain Navigator - Frontend Architecture

This document describes the frontend architecture and how it should integrate with future backend/ML services.

## Overview
The application is built using **Next.js (App Router)**, **React**, **Tailwind CSS**, and **Recharts**.
It uses a strictly typed frontend architecture where the mock data layer clearly delineates where the backend API boundaries will exist.

## Component Architecture

- **`src/app/`**: Route definitions using the Next.js App Router.
  - `page.tsx`: Public Landing Page.
  - `dashboard/layout.tsx`: Global Application Shell.
  - `dashboard/.../page.tsx`: Specific intelligence modules.

- **`src/components/`**: Reusable UI components.
  - `layout/`: `Sidebar.tsx`, `Topbar.tsx`
  - `ui/`: Standardized building blocks (e.g., `Card.tsx`).
  - `charts/`: Reusable chart wrappers (to be expanded).

- **`src/types/`**: TypeScript interfaces defining the Domain Model.

- **`src/data/`**: Mock data layer to be replaced by API calls.

## API Integration Strategy

Currently, the application relies on `mock.ts`. To integrate with the FastAPI backend, you should create a `src/services/api.ts` file that fetches data using standard REST patterns.

### Future Endpoints Required

1. **Dashboard Overview**
   - `GET /api/v1/dashboard/kpis` -> returns global metrics.
   - `GET /api/v1/dashboard/trends` -> returns time-series data for the main chart.

2. **Product Intelligence**
   - `GET /api/v1/products?category=...&region=...` -> returns list of products.
   - `GET /api/v1/products/{id}` -> returns detailed product metrics.

3. **Risk Center**
   - `GET /api/v1/analytics/outliers` -> returns the detected IQR outliers.

4. **AI Decision Center**
   - `GET /api/v1/insights` -> returns insights generated by the rule-engine/ML pipeline.

5. **What-If Simulator**
   - `POST /api/v1/simulate` 
   - Payload: `{ discount: 20, quantity_shock: 0, shipping_increase: 0 }`
   - Response: `{ predicted_revenue: 150000, predicted_profit: ... }`

## State Management
We use React's local state (`useState`) for page-level interactions (search, filters, simulation sliders). If global state (like active workspace or user identity) becomes complex, we recommend integrating `Zustand` or React Context.

## Styling
The application uses standard Tailwind CSS classes. Reusable utility classes are combined using `tailwind-merge` in `src/lib/utils.ts`.

## Visual Design Language
- "Retail Intelligence Command Center"
- Heavy use of whitespace, refined typography (Inter), and clear visual hierarchy.
- The Profitability Quadrant is built as a highly customized Recharts Scatter Plot.

## Getting Started

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

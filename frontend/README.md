# SalesBrain Navigator Frontend

This is the frontend implementation for the SalesBrain Navigator - an enterprise-grade AI-powered Retail Decision Support System.

## Stack
- Next.js 14 (App Router)
- React
- Tailwind CSS
- Recharts
- Lucide React

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the public landing page.
Navigate to the [Dashboard](http://localhost:3000/dashboard) to see the application shell.
